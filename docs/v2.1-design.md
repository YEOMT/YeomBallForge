# YeomBallForge v2.1 설계·전투 계약

기준 main: d6967bc22e8710bb296c47ee65916cbd4fa3ad6d. 규칙·콘텐츠 버전 2.1.0. 이번 문서는 실제 공통 시뮬레이터와 데이터, 아래 실행 증거를 기준으로 한다. 운영 배포 승인이나 AWS 용량 검증 문서가 아니다.

## 수업 루프와 책임

랭킹 수업은 퀴즈 → 공 슬롯 선택 → 강화 결과 확인 → 필요한 경로/공/히든/특성 선택 → 대기 → 정식 경기 → 결과/보관 공/퀴즈/비교 연습으로 순환한다. 랭킹의 3슬롯·공통 지갑·Elo와 기존 토너먼트/럼블의 한 공 출전은 분리한다. 경제와 실패·보호 규칙은 [v2.1-economy.md](v2.1-economy.md)를 따른다. 선택·출전·정산은 서버가 승인하며 시연/리플레이/연습은 보상을 지급하지 않는다.

## 콘텐츠 수와 원본 외형

- 기존 26개 + 신규 24개 = **50개 전투 프로필**, **508개 티어 폼**이다. T18~T11은 티어별 2종, T10~T1 전체 팩은 경로별 5종과 공용 6종, 히든 3종이다. 508개를 508개의 서로 다른 기믹으로 세지 않는다.
- 기존 26개 초상화를 유지한다. 신규 프로필의 portraitKey는 기존 이미지 별칭이며, 새로운 이미지 24개를 제작했다고 주장하지 않는다. 새 프로필은 구체 재질·문양과 실제 무기/오브젝트로 구분한다. orb/portrait/hybrid는 판정에 영향을 주지 않는다.
- 새 원형에서 가져온 것은 귀환·원호·과열·흡수·표식 같은 행동 구조다. 외부 캐릭터 이미지/음원/게임 코드를 복사하지 않았다.

## 공통 데이터 계약

폼은 ballId/formId, tier/level, classId/profileId, path, 최종 element, modifiers, portraitKey, glyph, renderMode를 가진다. classes.js의 각 프로필은 description/trigger/weakness, hpScale/mass/speed/bodyPower와 필요한 cooldown/windup/range/orbit/power를 제공한다. 존재하지 않는 폼을 더 높은 티어의 수치에 붙이지 않는다.

기본 HP는 200 + 6×level, 공격 계수는 10 + 0.5×level이며 폼 배율을 곱한다. 실제 피해는 기술 계수·최종 build.element·방어·유효 피해 제한으로 결정한다. 티어만으로 이동 속도가 증가하지 않는다. 화염→자연→대지→번개→물결→화염, 유리 ×1.20/불리 ×0.85를 유지한다. 공용·초반 폼은 최종 무속성을 사용한다. 클래스의 색/그림을 속성 판정으로 사용하지 않는다.

전투 스냅샷은 balls/objects/events와 tick을 함께 보낸다. balls에는 traitId, kx/ky, resource(name/value/max/ready), awakening, 상태, 현재 HP가 들어간다. objects에는 실제 판정 위치/반경과 필요한 x2/y2/angle/warning/hp/returning이 들어간다. 이벤트는 eventId/rootAttackId/tick/sourceId/targetId/type/kind/damage/blocked/impulse/element/reasonTags/procDepth를 포함한다. 반사·지속·소환·필드·파생 피해는 직접타와 구분하며, 요약은 실제 사건 합계와 eventId 참조로 만든다.

## 물리·발동·상한

기본 vx/vy와 피격 kx/ky를 분리했다. 실제 이동은 합성 속도를 425 world units/s 이하로 제한한다. 충돌 접근 속도에는 두 성분을 포함하고 질량으로 반응을 분배한다. 넉백은 매 틱 0.955로 감쇠하며 무게 중심 특성은 해당 공유 매개변수를 사용한다. 몸체/무기/투사체는 swept-circle 판정을 사용하고 벽/겹침 뒤 다시 전장 안에 고정한다. 철퇴의 벽 추가 피해는 유효 강타가 지정한 한 번만 적용한다. 보통 벽 반사는 피해를 만들지 않는다.

전역 투사체 120, 필드 30; 공당 기본 투사체 6, 필드 3; 표시용 이벤트 링 128개다. 사역마/분신은 별도 생존자로 세지 않는다. 서버 원본 기록은 표시 링의 새 seq를 매 시뮬레이션 단계에서 모아 보존한다. 모든 벽 충전은 재발동 간격을 가지며 광역 직접타는 rootAttackId 단위로 한 번만 성장한다. 파생 피해는 특성을 다시 충전하지 않는다.

1:1은 최대 40초, 30초부터 초당 10 + 12×(30초 이후 경과시간)의 동일 환경 압박을 매 틱 분배한다. 럼블의 45초 축소/90초 압박/120초 한도는 유지한다. 랭킹은 outcomePolicy=ranking으로 완전 동률·같은 틱 상호 KO를 무승부로 처리하며 토너먼트만 기존 진출자 결정 정책을 사용한다.

## 전투 중 성장과 T1

철퇴의 벽 충전, 방패 반격, 삼중검의 적중 박자, 반응로/톱의 과열, 표식 소비·흡혈은 각각 자신의 실제 사건으로 동작한다. 새 전투에서 체력·쿨다운·저장 탄환·표식·특성 자원·되감기/재형성 횟수를 다시 만든다. 과거 전투 상태가 강화나 다음 경기로 이어지지 않는다.

T1 조건부 각성은 검증한 8개(mace, trinity, tide, beam, bolt, frost, summoner, star)에만 적용했다. 체력 35% 이하에서 경기당 1회, 3초 동안 공격 ×1.12. 상시 무적이나 전 속성 우위는 없다. 나머지 프로필에 미구현 각성이 있다고 표시하지 않는다.

흡수모사는 명시된 허용표(ring→cleave, mace→cleave, thorn→cleave, trinity→cleave, saw→cleave, greatsword→cleave, elastic→cleave, blade→crescent, frost→coldwave, fracture→coldwave, cannon→bolt, sniper→bolt)만 사용한다. 히든·복사·부활·소환 능력은 복사하지 않으며 해당 상대에는 복사 불가 상태를 표시한다. 흡혈은 실제 유효 피해의 30%, 회당 최대 HP 3.5%, 최소 60틱 간격이고 동시 치명 피해 후 부활시키지 않는다.

## 특성 데이터와 호환표

특성 한 칸을 T10부터 사용한다. 후보는 프로필별 고정 3개이며 별도 재화/리롤/희귀도가 없다. 설명과 대가의 숫자는 TRAITS.params에서 생성하고 시뮬레이터도 같은 값을 읽는다. 호환되는 기존 선택은 유지하고 최종 폼/히든 결정 뒤 필요한 경우에만 다시 선택한다. 강화/퀴즈/Elo를 수정하는 특성은 없다.

- **벽 축전 (wall_charge)**: 유효 벽 반사 3회 뒤 다음 직접 피해 ×1.35. 충전 1개, 6초 유지. 대가: 기본 직접 피해 ×0.94
- **무게 중심 (stability)**: 받는 넉백 ×0.65, 넉백 감쇠 0.9. 밀려나도 더 빨리 자세를 회복. 대가: 이동 속도 ×0.94
- **연계 박자 (impact_rhythm)**: 3초 안에 직접타 3회 후 다음 직접 피해 ×1.3. 대가: 기본 직접 피해 ×0.95. 파생타는 충전하지 않음
- **반격 준비 (guard_riposte)**: 유효 방어 뒤 2초 동안 다음 직접 피해 ×1.3. 충전 1개. 대가: 기존 방어 효율 ×0.85
- **긴 무기 (long_reach)**: 회전 무기의 실제 궤도 반경 ×1.2. 대가: 회전 속도 ×0.82
- **회수 숙련 (quick_return)**: 방패가 실제 귀환하면 다음 준비시간 ×0.65. 대가: 비행 중 피해 ×0.85
- **잔열 (residual_heat)**: 고유 화염 직접타 뒤 1초 동안 2회의 잔열. 각 기본 공격 계수 ×0.08. 대가: 직접 피해 ×0.94. 대상별 중첩 1
- **빙결 균열 (frost_fracture)**: 감속 중인 상대에게 직접타 표식 2개를 모아 파쇄 계수 0.4. 대가: 감속 지속시간 ×0.75. 소환·반사·지속 피해는 표식 제외
- **집중 포격 (pulse_focus)**: 차지 공격의 폭 ×1.35 또는 관통 +1. 대가: 차지 예고 시간 ×1.3
- **소수 정예 (squad_focus)**: 사역마 또는 분신 최대 1개. 사역마 발사 간격 ×0.72, 분신 체력 ×1.5. 대가: 동시 소환 수 2 → 1
