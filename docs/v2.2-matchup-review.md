# v2.2 심층 상성 전후 검토

전체 균형은 아직 목표에 도달하지 않았다. 동일 조건의 24개 위험 상성 중 **17개가 A 승률 20~80% 밖**이고, 합법 T5 전체 그리드의 **49개 중 28개 프로필이 승률 35~65% 밖**이다. 24개 상성만으로 모든 조합을 대표하지 않으며, 승률 개선을 진화 효과의 단독 인과 증거로 해석하지 않는다. 이번 검토에서는 런타임을 수정하지 않았다.

## 비교 범위와 해석

- 이전 버전: main `cad650262eb44bff828c3b664b79b97cf74d5db1`의 보존 사본. `artifacts/v22-baseline-final-balance.json` 25,904경기와 `v22-baseline-selected-balance.json` 2,400경기 중 심층 24개 대진을 사용했다.

- 대진마다 합법 T5, 기본 속성, 추가 전술 특성 없음, **100개 시드 × 좌우 2배치 = 200경기**. 시드는 `1009 + i × 7919` (i=0..99). 원시 matches 파일의 프로필·티어·시드·좌우 키를 비교하여 **이전/현재 4,800개 입력 모두 동일**함을 확인했다. T1 각성, 강제 준비 fixture, basic 불법 T5는 아래 표에 없다.
- 표의 승/무/패와 승률은 왼쪽 A 기준이다. 무승부는 별도로 세며 승리로 환산하지 않는다. 95% 구간은 분석기의 Wilson 이항 구간으로, 같은 시드의 좌우 쌍 상관과 24개 다중 비교를 보정한 인과 추론 구간은 아니다.
- `pressureShare`는 경기별 실제 압박 피해 / 전체 실제 피해를 구한 뒤 200경기를 평균한 값이다. 압박으로 마지막 KO가 난 경기 비율과 다르다. 자연 KO는 30초 압박 시작 전 공격으로 끝난 경기다. 30초 이후 공격/압박 혼합, 공격 단독, 동시 무승부는 별도 분류다.
- 전체 25,904경기는 자연 KO 2806→3325 (10.8%→12.8%), 압박 KO 19702→18911 (76.1%→73.0%)다. **합법 T5 그리드만** 보면 압박 KO 13997/18816=74.4%, 평균 압박 피해 비중 35.5%다. 분모가 다른 73.0%와 74.4%를 섞지 않는다.

## 소환 6개 핵심 상성: 확인된 경로와 남은 가설

공통으로 확인한 코드는 [arena.js](../packages/sim/arena.js)의 `familiar`·`shadow`·`defend`, [mechanics.js](../packages/sim/mechanics.js)의 `captor`, [evolution.js](../packages/sim/evolution.js)의 사역마 업그레이드 경로다. 일반 사역마는 탐색 반경 185, 탄속 245, 탄 수명 50틱, 유도 혼합 .035, 발사 간격 72틱을 사용한다. 일반 진화는 한 사역마의 크기와 발사 간격을 최대 150틱만 변경한다. 개수/수명 제한과 반사탄 재포획 금지는 유지된다. 이는 코드와 회귀 검사가 확인한 **작동 사실**이며, 아래 승률 변화의 단독 원인이 입증됐다는 뜻은 아니다.

- **소환–철퇴:** 100%→93%로 줄었지만 186승/3무/11패다. 철퇴의 회전 무기·안쪽 사각과 사역마의 원거리 발사는 서로 다른 접촉 조건을 가진다. 새 접근 회전 .020rad/tick, 성장 머리와 벽꿍이 실제 적용되는 것은 검증했다. 그러나 현재 직접 철퇴+벽꿍은 비압박 피해의 20.3%, 그림자 탄환은 37.5%다. **추정:** 철퇴가 사거리 안에 머무는 시간보다 사역마의 공격 기회가 더 안정적이다. 아직 발사 횟수 대비 명중, 무기 접근 횟수 대비 접촉률, 진입 중 피격·이탈 시간을 별도 계측하지 않아 이를 인과로 확정하지 않는다.
- **소환–삼중검:** 100%→79%, 158승/8무/34패로 점추정은 목표 범위 안에 들어왔다. 제한된 접근 회전 .008rad/tick, 세 검의 실제 회전 접촉, root당 한 번의 연계 검기가 실행된다. 비압박 피해는 shadow 34.5%, trinity 24.6%, 연계 검기 1.6%다. **추정:** 접근 기회와 회전 접촉 개선이 차이를 줄였지만, 그 효과를 소환 발사 간격/유도/업그레이드 제한과 분리하지 않았다. 95% 구간 상한도 80%보다 높으므로 “균형 완료”로 처리하지 않는다.
- **소환–해일:** 100%→94.5%로 여전히 극단적이다. 해일은 실제 전면 피격과 29틱 방어 간격, 2회 방어 후 반경 76의 반격 조건을 가진다. 사역마 공격은 더 먼 거리에서 시작할 수 있다. 현재 자연 KO는 **0/200**, 압박 KO는 **172/200**, 평균 압박 피해는 14.2%→38.9%로 늘었다. **확인된 결론:** 처치가 늦어졌지만 상성은 균형을 얻지 못했다. 전후면 피격 비율과 방어 후 반격이 실제 사거리 밖에서 소모되는 비율을 계측해야 한다.
- **소환–빔:** 100%→99%로 사실상 개선되지 않았다. 빔은 36틱 예고 시 고정한 직선으로 발사하고 이후 150틱 재충전한다. 그림자 탄환은 이동 중 짧게 유도된다. shadow 43.9% 대 beam 15.0%는 공격 종류의 실제 비중 차이다. **추정:** 긴 고정 조준의 기회 비용이 누적 탄환보다 크다. 빔 예고 후 상대의 선 이탈률, 빔 실제 발사·명중 횟수, 사역마와 본체의 거리별 교환을 먼저 측정해야 하며 자동 명중이나 무제한 폭 확장은 해결책으로 간주하지 않는다.
- **소환–별먹이:** 44.5%→6.5%로 오히려 극단적인 역상성이 됐다. 별먹이는 준비된 상태에서 실제 탄환 피해를 0으로 만들고 그 탄환을 제거하며 반격 준비를 얻는다. 현재 starcounter 40.2%, shadow 21.8%이고 이는 실제 피해 원장이다. **추정:** 소환의 빈도/유도 완화와 별먹이의 흡수 후 진화가 함께 작용했을 수 있으나, 이번 비교는 묶음 변경이므로 어느 변경이 38%p 차이를 만들었는지 입증하지 않았다. 흡수 준비 시간 대비 소환 발사 시간 분포와 반격별 실효 피해를 같은 시드에서 분리해 확인해야 한다.
- **소환–포획:** 14%→0%, 0승/0무/200패다. 포획은 반경 48의 비반사 탄환을 최대 2개 저장하고 실제 원본을 제거한 뒤 방향성 반환한다. shadow는 이 포획 조건에 들어가며 반사 반환탄은 재포획하지 못한다. shadow 비중은 5.3%, captured는 28.5%다. **확인된 경로:** 소환 공격을 제거하고 역으로 사용한다. **추정:** 2개 저장 상한과 60틱 반환 주기가 현재 소환 공급량을 너무 완전하게 상쇄한다. 정상 약점의 존재와 0% 승률의 적정성은 별개이며, 포획 중 가득 찬 시간/누출 탄환 수/실제 근접 기회를 다음 판단 자료로 요구한다.

## 후속 조정의 우선순위와 완료 기준

1. **소환의 양극단:** 철퇴/해일/빔에 93~99%인 동시에 별먹이/포획에는 6.5%/0%다. 전역 공격력 증감은 양쪽을 동시에 해결하지 못한다. 사역마 공급 간격·유도 기회, 흡수/포획의 준비·포화 시간, 근접 진입 실패 원장을 먼저 수집하고 한 변수씩 같은 시드에서 비교한다.
2. **고유 수단이 약하거나 상대에 따라 사라지는 프로필:** current, mason, decoy는 방어/설치 효과가 승리 기회로 연결되는지 확인해야 한다. mimic은 복사 불가 reactor뿐 아니라 복사 가능한 blade에도 전패한다. 고유 공격이 없는 유틸리티형에 일괄 공격력 버프를 주는 대신 실제 경로 변경/방어가 만들어낸 유효 후속 행동을 계측한다.
3. **압박으로 갈리는 유사 균형:** reactor/crystal은 승률이 가까워도 자연 KO 0, storm/tide와 beam/tide도 0이다. phoenix/rewind는 생존 시점 문제를 우선 검토한다. 공통 HP·425 속도 상한·30초 압박 정책을 임의로 바꾸거나 압박 KO 감소만을 성공으로 취급하지 않는다.
4. **개선된 사례의 회피성과 재현성 유지:** elastic/mace, portal/trinity, saw/beam을 유지 대상으로 삼되, 다른 상성/양쪽 배치/시드 확대에서 목표 범위와 조작 없이 읽히는 예고를 함께 검사한다. 현재 200경기는 100개 시드의 양쪽 배치이므로 독립 200시드라고 표기하지 않는다.

위 원인 분리 실험과 추가 조정은 **NOT RUN / 미완료**다. 24개 심층 상성 모두를 20~80%로 맞췄다거나 49개 프로필 전체가 균형 잡혔다고 보고하지 않는다. 조건부 진화/49개 각성의 실제 실행 검증과 경쟁 밸런스의 완성은 별개다. 다음 변경은 새 브랜치/검토 범위에서 검증하고, 현재 동결된 코드와 최종 검사 결과를 보존한다.
