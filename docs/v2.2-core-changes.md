# v2.2 전투 경로 및 조정 근거

기준은 `cad650262eb44bff828c3b664b79b97cf74d5db1`의 v2.1이다. 이 문서는 구현과 기계적 검사 기록이며, 자연 경기 전체 밸런스 판정은 `v2.2-balance.md`를 별도로 참조한다.

## 실제 전투 경로

`arena.js`의 hit → 전술 처리 → 각성 피해 잔여량 사전 제한 → 방어 → 각성 실제 피해 예산 예약 → 상태/충격량 → 동시 피해 배분 → HP/KO 경로를 사용한다. `impactKind/impactGrade`, 접촉점과 normal, 실제 피해·방어량·충격량, 원본 root, 진화/각성 ID가 같은 사건에 남는다. 피해 0은 충격량 0/강도 0이며 추가 상태나 벽꿍을 주지 않는다. 기존 425 속도 상한, .955 충격 감쇠, 질량 기반 충돌, 상대 이동을 포함한 swept 검사는 유지한다.

일반 진화 상태는 `evolution.js`에서 50개 정의를 실행한다. 양수 유효 사건과 중복 root 검사를 거친 뒤 준비/활성화/소모/종료를 분리한다. 파생 피해는 범용 직접 적중을 다시 채우지 않는다. 소환 피해는 독립 root와 12틱 간격을 요구한다. 이동 충전은 snapshot에 정확한 값을 남기되 진행 사건은 10% 경계에서만 내보낸다. 전술 자원, 기존 코어 자원, 진화 자원을 서로 대체하지 않는다.

대표 8종을 먼저 실제 조건과 효과로 검사했다. 이후 50종 모두 준비 조건 원장·중복 root, 소모·만료·초기화, 각성을 끈 준비 상태 A/B를 검사한다. A/B는 실제 물리·무기/필드 형상·피해·회복·방어 타이밍의 차이를 비교하며, 이름/색상/진화 상태 차이는 증거에 넣지 않는다. 준비 시연으로 정상 경기의 자연 발동률을 입증하지 않는다.

`node tools/impact-v22-analysis.mjs`는 보존한 기준 디렉터리와 현재 코드를 같은 합법 T5 폼/입문 T19 대상/위치/속도로 실행한다. 40개 준비 fixture, 첫 실제 적중 후 100/200/350ms 이동 거리·변위·좌표, 최대 이동 속도, 원본 사건, root 총피해와 벽꿍을 기록한다. `evolved` fixture만 신규 준비 조건을 명시적으로 배치한다.

- 같은 벽 충전에서 **v2.2의 진화 준비 조건까지 명시적으로 배치한** 철퇴: 충격량 268.75 → 327.875, 350ms 이동 경로 43.13 → 48.97, 벽꿍 5.6 → 6.4. 진화가 없는 벽 충전은 양 버전 모두 268.75/43.13/5.6이며, 비충전 철퇴도 215로 동일하다. 신규 진화의 물리 효과를 기본 철퇴 전체의 상향으로 해석하지 않는다.
- 해일 반격: 92 → 115, 같은 350ms 경로 21.12 → 26.40. 전면 방어 4.095, 후면 0을 동일 fixture에서 유지했다.
- 돌진: 실제 최대 이동 속도 360.75 → 378.79로 425 아래다. 냉기: 같은 root의 시간차 파쇄가 실제로 추가되며 감속 만료 후 파쇄되지 않는다.
- 빔 회피 fixture는 양 버전 모두 피해 0이다. 폭 변화는 실제 서버 선분의 반폭을 늘리고 발사자의 반동을 준다. 소환·별빛은 억지 넉백 대신 실제 교체/흡수/반환 기믹을 비교한다.

## 최종 경계 상태 검사

Mason은 소유권을 바꾼 반사탄까지 공당 6개 상한을 지키며, 초과 반사탄은 소멸한다. 귀환 중인 방패는 원래 소유자를 유지한다. 파괴된 분신은 같은 틱의 다음 탄환까지 계속 막지 않는다. 취소/만료 객체는 이후 이동·충돌 경로를 실행하지 않는다. 흡수·파괴된 귀환 방패의 소유자는 다음 틱에 60틱 회복을 시작하므로 영구적인 방패 부재 상태가 남지 않는다. 이 세 가지는 개별 회귀 fixture로 검사한다. 각성 피해 예산은 방어 전에 남은 양을 제한하고 실제 방어 후 예약하여 소진된 공격의 가짜 방어량/반격 충전을 방지한다. 거인 질량은 진화/각성을 곱하지 않고 최대 2로 제한한다.

변신 진화는 다음 예정 형태에만 적용한다. 질주형은 속도 ×1.12로 이동하고 첫 실제 몸체 적중 또는 90틱 만료에 기본 218로 돌아온다. 사격형은 예정된 탄환 하나의 실제 반경 ×1.2, 방어형은 첫 양수 방어의 비율 ×1.2 후 기존 방어로 복귀한다. 세 형태 능력을 동시에 주지 않는다. T1 각성은 기존처럼 해당 키를 대체하므로 일반 진화와 곱하지 않는다.

사용하지 않거나 실행 시점상 효과가 없던 메타데이터 네 항목을 제거했다. 시간유리는 기존 반향 지연을 유지하고 실제 반향에 `echoPush:62`, 저주는 기존 30틱 파열 지연을 유지하고 `cursePush:65`를 적용한다. 음파는 `range:1.15`의 실제 범위 변화이며 추가 고리 세 개를 생성한다고 주장하지 않는다. 되감기는 기존 한 번의 복구에서 `rewindRestore:1.15`를 적용하고, 기존 이동 사건의 출발/도착 잔상 표시를 사용한다. `echoDelay`, `curseDelay`, `sonicRings`, `rewindTrail`을 구현된 추가 기믹으로 집계하지 않는다.

이 최종 조건 수정 후 `node --test tests/combat.test.js tests/combat-v21.test.js tests/evolution-v22.test.js tests/awakening-v22.test.js`는 188/188 PASS다. 대상 분리·같은 형태 중복 방지·예정된 세 형태의 실제 효과·기존 각성 방어 대체 동작까지 교차 검사했다. 이 수치는 전체 프로젝트 검사나 정상 경기의 자연 발동률을 대체하지 않는다. 정상 경기 전수 분석과 실시간 15분 검사는 최종 통합 보고의 결과를 따른다.
