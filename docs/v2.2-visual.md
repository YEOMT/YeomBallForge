# v2.2 전투 표시·음향 검증

## 구현

`public/arena.js`는 서버의 실제 위치·반지름·무기·투사체를 렌더링합니다. 철퇴 머리/손잡이, 삼중검, 귀환 방패, 사역마, 톱니 등을 구분하고, 파동포·열선의 폭은 사건의 실제 `r × 2`, 선분은 `endX/endY`, 균사/광로 선분은 `lineR`, 씨앗/중력장의 폭발 예고는 `dangerR`, 부채꼴은 `r/angle/halfAngle`을 읽습니다. 실제 감속 상태에만 냉기 조각을 표시합니다. 경고선·실제 무기·HP·이름은 저사양에서도 유지합니다.

접촉 사건의 실제 피해·충격량·방향·분류로 둔타, 절단, 벽 충돌, 방어, 냉기, 전기, 물결, 소환, 흡수를 구분합니다. 강타는 방향 압축과 국소 충격/스파크, 검격은 짧은 절단선, 흡수는 안으로 모이는 선입니다. 탄성 주먹과 고정 포탈 출구·각성 후속 질주는 실제 예고 사건의 방향/범위/기간을 표시합니다. 표시용 정지는 사건당 최대 90ms, 1초 합계 120ms이며 럼블과 모션 줄이기에서는 비활성입니다. 시뮬레이션·HP·승패에는 관여하지 않습니다. `PresentationClock`의 기존 범용 API 100ms 상한은 과거 호환으로 유지하되 새 사건 레시피는 90ms를 넘기지 않습니다.

상단을 별도 영역으로 할당하고 긴 파랑 HP + 빨강 잔상 + 빈칸을 좌우 반대로 채웁니다. HP 수치, 남은 시간, 고유 기믹 게이지, 독립적인 진화 진행, 각성 상태, 전술/상태를 표시합니다. 공 아래에는 플레이어 이름만 표시합니다. 회복은 실제 `healing` 값에 따른 초록 숫자이며 HP 잔상도 즉시 재설정합니다.

`combat-feedback.js`의 이펙트 예산은 일반 96개/저사양 24개입니다. 가득 찼을 때 투사체 발사·벽 장식보다 실제 공격 예고·유효 접촉·방어·회복·KO를 우선 보존합니다. 모드 변경 시에도 즉시 해당 상한으로 줄입니다. 초상화 캐시 50개, 재질 캐시 최대 180개, 텍스트 맞춤 캐시 약 600개, 저사양 피해 숫자 스프라이트 최대 96개, 표시 프레임 최대 64개를 유지합니다.

음향은 종류별 저음/접촉/잡음 등 최대 두 층을 합성합니다. 유리·유기체·중력·탄성·화염·시간 반향·저주·음파 재질을 나누고 원본 소환, 사역마 발사, 사역마 적중도 분리합니다. 루트+재질별 중복 및 연타 빈도(절단 40ms, 나머지 65ms)를 제한합니다. 동시 SFX 4음성/8음원, BGM 최대 2음원이며 마스터 compressor와 개별 gain 상한을 둡니다. 소리만으로 피해를 꾸미지 않고 0 피해·압박 틱을 충돌음에서 제외합니다. 숨은 탭, 표시 경기 교체, mute, replay 종료 때 해당 owner 노드를 정리합니다. 리플레이/시연을 라이브 화면 위에 열면 가장 최근 표시 owner만 소리를 내며, 닫으면 이전 owner의 이후 사건을 다시 듣습니다.

24개 신규 초상화는 모두 저장소에 작성한 독립 SVG입니다. [원본 초상화 모음](evidence-v2.2/visual/24-original-portraits.png), [50개 자산 manifest](../public/assets/balls/manifest-v2.2.json), [출처 기록](../THIRD_PARTY_NOTICES.md)을 참조하세요. 재질 모드에도 신규 24개의 서로 다른 선 문양을 사용합니다. `orb` / `portrait` / `hybrid`를 유지합니다. 도감·선택 카드·강화 카드의 진화와 T1 각성 설명은 콘텐츠 모듈에서 가져오며, 합법적인 T1 카드에서 별도의 각성 시연을 엽니다.
