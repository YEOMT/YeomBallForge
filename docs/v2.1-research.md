# v2.1 조사와 적용 기록

작성일: 2026-11-26 (Asia/Seoul). 입력은 사용자가 제공한 [v2.1 명세](../spec/v2.1-research-update.txt)와 [v2 기반 명세](../spec/v2-foundation.txt)다. 아래는 이번 구현에서 직접 열어 재확인한 출처와 적용 판단을 구분한 기록이다. 설치 플레이·실기기 측정 결과로 제시하지 않는다.

| 직접 확인한 공식 출처 | 확인한 내용 | 이번 코드의 독립적인 적용 |
|---|---|---|
| [Random.GG BALL//FIGHT](https://www.random.gg/ballfight) | 이름·작품 검색, 형태 탭, 재생 속도, 음악·효과음 제어 | 이름·능력 검색, 다음 티어 후보 확인, 분리 음량, 기록 재생 속도. 베팅·관전 보상은 도입하지 않음 |
| [Ball Game v1.6 개발 로그](https://bluecoyotestudio.itch.io/ball-game/devlog/1642711/ball-game-update-v16) | 소환 가능 빌드에만 소환 카드, 수치 툴팁, 패링 효과, 투사체 상한·최소 쿨다운 | 프로필별 고정 3개 호환 특성, 동일 데이터 설명, 사건별 방어 표현·발동 상한 |
| [Ball Game v1.1 개발 로그](https://bluecoyotestudio.itch.io/ball-game/devlog/1495365/ball-game-update-11) | 배속, 지정 시드에서 진행 보상 분리, 최초 선택·중복 클릭 개선 | 기록 재생과 비교 실행 분리, 연습에 Elo·재화 없음, 서버 명령 중복 방지 |

위 기능의 존재와 YeomBallForge에서의 효과는 별개다. 이 기능이 학습 효과나 장기 재미를 입증한다고 주장하지 않는다. 시연·리플레이·수업 팩은 현재 공통 시뮬레이터와 콘텐츠 규칙으로 구현했다.

명세에 포함된 BalanGo, Gladiorb, BALLRENA, Super Auto Pets, Backpack Battles, Ballionaire, BALL x PIT 조사는 **사용자가 제공한 조사 자료**다. 이번 실행에서는 이 게임들의 설치 플레이와 전체 소스 검증을 하지 않았다. 해당 제품의 세부 기능을 이번 작업에서 새로 검증한 사실로 바꾸지 않는다. 원문 출처는 명세의 S3·S8~S14에 남아 있다.

[HannamBalls battle-core.js](https://github.com/igomq/HannamBalls/blob/master/src/battle-core.js)는 이번 웹 조회에서 가져오지 못했다. 해당 코드의 라이선스·현재 구현을 확인 완료했다고 표시하지 않으며 코드를 이식하지 않았다. Howler/AetherFX/effectcraft도 추가하지 않았다. 효과음은 네이티브 WebAudio의 합성음, 그림은 기존 자산과 Canvas 코드다.

구체 재질은 외부 게임이 아닌 이 저장소의 과거 커밋 `23c5c341e5b105c9711635870f53d14895d4921f`에 있던 `skin()`을 참고해 별도 `orb-materials.js`로 복원했다. 현행 무기·소환·표시 보간을 덮어쓰지 않았다. 추가 의존성·외부 캐릭터 이미지·게임 음원의 반입은 없다.
