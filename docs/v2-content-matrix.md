# v2.1 콘텐츠 목록

50개 행동 프로필(기존26+신규24), 508개 폼, 기존26개 초상화. 폼/이미지를 기믹 수로 합산하지 않는다. 전체 경로 후보와 특성 호환은 [설계 문서](v2.1-design.md)를 따른다. 모든 50개 시연에서 해당 프로필의 실제 사건이 확인됐다.

| 프로필 | 새 행동 | 발동 | 대응 |
|---|---|---|---|
| returner · 귀환방패 | 방패가 벽에 반사된 뒤 돌아온다. 손에 돌아오기 전에는 방어할 수 없다. | 투척 → 벽 반사 → 실제 회수 | 방패가 날아간 동안 근접 공격 |
| pendulum · 진자거미 | 벽 고정점 주위를 원호로 움직인 뒤 줄을 끊고 관성 돌진한다. | 벽 고정과 원호 운동 | 원호 경로에 장판 놓기 |
| reactor · 철갑반응로 | 부채꼴 미사일 살보가 반동을 만들고 세 번 발사하면 냉각한다. | 살보와 과열 3회 | 냉각 중 느려진 이동 |
| captor · 염력포획 | 탄환 두 개까지 공전시킨 뒤 약화해 되던진다. 반사탄은 붙잡지 않는다. | 근처의 비반사 탄환 | 근접 공격 또는 세 번째 탄환 |
| rewind · 시간되감기 | 한 경기 한 번, 최근 자기 위치로 돌아가 잃은 체력 일부를 회복한다. | 최대 체력의 18% 손실 | 회복 상한 이후 지속 압박 |
| mason · 연성벽 | 예고한 짧은 벽을 세워 공과 탄환의 반사 경로를 바꾼다. | 벽 위치 예고 20틱 | 벽 끝을 우회 |
| morph · 변신시계 | 질주·사격·방어의 세 형태를 고정 순서로 바꾼다. 전환 직후 빈틈이 생긴다. | 형태 3종 순환 | 다음 형태와 전환 틈 노리기 |
| titan · 축소거인 | 작은 빠른 몸과 큰 무거운 몸을 교대한다. 실제 반지름도 변한다. | 작음 ↔ 큼 | 큰 몸의 넓은 피격 범위 |
| phoenix · 잿불불사조 | 한 경기 한 번 치명 피해에서 낮은 체력으로 재형성하고 불꽃 고리를 남긴다. | 최초 치명 피해 | 재형성 뒤 낮은 체력 |
| thermal · 괴수열선 | 긴 충전 뒤 천천히 회전하는 열선으로 좁은 부채꼴을 쓸어낸다. | 긴 충전 → 제한된 회전 | 옆과 뒤에서 공격 |
| curse · 저주매듭 | 같은 상대 직접타 세 번으로 쌓은 피해 일부를 잠시 뒤 전달한다. | 직접타 세 번 | 표식 만료까지 거리 벌리기 |
| cards · 마법카드 | 미리 보이는 방어·탄환·구속 카드를 정해진 순서로 발동한다. | 카드 3종 순환 | 공격 카드가 아닐 때 접근 |
| saw · 톱니분쇄 | 톱이 연속 접촉하면 강해지고 열이 차면 멈춘다. | 짧은 간격의 실제 톱 접촉 | 거리 벌리기와 과열 틈 |
| sniper · 표적저격 | 이동을 예측한 조준선을 고정하고 준비 후 빠른 관통탄을 쏜다. | 위치 예측 → 고정 조준 | 조준 뒤 방향을 바꾸기 |
| trail · 광선궤적 | 짧은 이동 궤적을 남겨 가로지르는 적을 한 번 감속시킨다. | 짧은 선분을 실제 횡단 | 빛의 선을 우회 |
| mimic · 흡수모사 | 상대 대표 공격 중 허용된 베기·감속파·직선탄 하나를 약화해 사용한다. | 상대 공격 유형 확인 | 복사 불가 유형과 긴 재사용 |
| greatsword · 축력대검 | 이동 거리를 충전해 넓은 부채꼴 한 번을 베고 긴 회복에 들어간다. | 이동 축력 → 부채꼴 베기 | 예고 뒤 후방 이동 |
| storm · 천둥구름 | 적의 이전 위치를 세 번 예고하고 그 자리로 시간차 낙뢰를 내린다. | 고정된 위치 표식 | 표식 밖으로 이동 |
| current · 조류술사 | 짧게 흐르는 물길이 진입한 공과 탄환의 궤적을 휘게 한다. | 흐름 구역 생성 | 질량과 진입 각도로 견디기 |
| decoy · 거울분신 | 낮은 체력의 분신이 탄환과 근처 공격 일부를 대신 받는다. | 표적 가능한 짧은 분신 | 범위 공격과 분신 파괴 |
| mycelium · 균사그물 | 세 씨앗 노드를 잇는 선을 가로지르는 적을 잠깐 얽는다. | 최대 3개 노드 연결 | 연결선 우회 |
| vampire · 흡혈월식 | 간격을 지킨 근접 적중에서 실제 준 피해 일부만 회복한다. | 유효 근접 피해 | 원거리 견제와 방어 |
| fracture · 빙정파쇄 | 냉기 직접타로 표식 두 개를 모은 뒤 다음 직접타로 파쇄한다. | 냉기 표식 축적 → 소모 | 표식 만료까지 피하기 |
| combo · 연속격파 | 제한 시간 안의 세 직접타 다음 공격이 발사 강타가 된다. | 직접 적중 리듬 | 적중 사이 시간 벌리기 |

[50개 실제 시연과 816경기](v2.1-combat-analysis.json). 이번 원형은 동작 아이디어만 참고했고 외부 이미지/음원/게임 코드를 복사하지 않았다.
