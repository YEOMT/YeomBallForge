# v2 브라우저 검증

검증일: 2026-11-25. 관리형 로컬 미리보기와 실제 Chrome UI에서 수행했다. 이 문서는 공개 서버 30명 접속을 실측했다는 뜻이 아니다. 네트워크 검증은 별도 문서를 참고한다.

## 실제 조작으로 확인한 흐름

- 홈의 4개 경로 미리보기 초상화가 로드되고 연습 시작 버튼이 작동한다.
- 연습의 참가 공 수를 4개로 설정하고 샘플 퀴즈를 시작했다.
- 첫 문항 정답 후 강화권이 기본 10장에서 12장으로 바뀌고 정답 피드백이 표시된다.
- 강화 시작 화면은 T20, 12장으로 시작했다. T19 성공 후 11장을 표시했다.
- T18 성공 시 두 후보(초승달 연습검·작은 철퇴)가 나타나고 다음 강화는 선택 완료까지 비활성화된다.
- T18에서 T11까지 티어별 후보를 선택해 정상 진행했다.
- T10 성공 시 8개 경로가 나타났다. 검술 선택 뒤 경로 볼 2개와 공용 볼 6개가 나타났다.
- 선택 대기 중 시간이 끝나자 선택한 검술 경로의 첫 볼을 자동 확정하고 전투가 시작됐다.
- 흰 전장, 진한 테두리, 원형 캐릭터 초상화, 이름과 티어, HP 현재/최대가 표시됐다.
- 교사 중계 체험에서 다른 진행 경기를 선택하자 중계 제목과 실제 경기 화면이 바뀌었다.
- 재생 속도를 4배로 변경하고 토너먼트가 최종 결과까지 끝나는 것을 확인했다. 개인 순위·유효 피해·처치·탈락 기록과 다시 하기 버튼이 표시됐다.

## 검증 범위

정적 모듈 의존성 검사에서 모든 로컬 import 대상이 `dist/`에 존재했다. UI 카드의 268개 형태 HP·공격력은 전투 엔진의 수치와 대조했다. 실시간 역할·재접속·개인 결과는 자동 테스트와 31소켓 통합 검증으로 별도 확인했다.

이 기록은 실제 휴대전화, 학교 무선망 또는 장시간 다중 교실 사용의 검증을 대신하지 않는다. 외부 WSS 서버를 연결한 뒤 공개 페이지에서 서로 다른 기기로 방 참가부터 최종 결과까지 추가 확인해야 한다.
