# v2.1 강화·보관·결과 화면 검증

`tools/forge-flow-v21-browser.mjs`는 임시 로컬 HTTP 서버와 headless Chromium에서 **명시적으로 배정한 UI 상태와 명령 어댑터**를 사용한다. 자연 발생 강화 확률, 정식 서버 권위, AWS 성능 또는 실제 모바일 기기 검증으로 해석하지 않는다. 서버의 실제 WebSocket·경제·인벤토리 검증은 `tests/ranking.test.js`, `tests/forge-v21.test.js` 및 `tools/browser-v21.mjs`가 담당한다.

## 변경

- 다음 티어에 가능한 폼과 발동 능력은 공유 `getBallChoices` 및 현재 팩에서 계산한다. 미발견 히든을 예고하거나 추첨하지 않는다.
- 결과 확인 이전에 선택 버튼을 노출하지 않는다. 서버 영수증의 `immutableCandidates`를 사용하고, 같은 `classId`의 합법 후보가 있을 때만 같은 계열 선택 단축 버튼을 표시한다. 선택 중에는 이전 폼에 새 티어의 스탯을 붙여 표시하지 않는다.
- 세 보관 슬롯의 이름·경로·출전 속성·행동 필터를 제공한다. 지갑·순위 갱신 시 필터 입력 노드를 보존하고 빈 슬롯은 필터와 무관하게 유지한다.
- T20 초기화 결과에서 결과 확인과 함께 보관 공·퀴즈·현재 코어 재육성으로 이동한다. 보관 잠금은 출전 잠금과 다르며 기존 공을 그대로 출전할 수 있다.
- 최근 경기의 같은 공 재도전은 보존된 경기의 `instanceId`와 현재 슬롯을 대조한 뒤 **현재 슬롯**을 서버 큐에 제출한다. 과거 빌드를 복원하지 않고 삭제·재생성된 슬롯으로 잘못 출전하지 않는다.
- 종료 자동 확정의 슬롯·공·경로·특성을 최종 화면에 표시한다. 무효 경기의 사유와 기록 상한에 따른 매칭 대기 안내를 표시한다.
- 새 경기 배정이나 수업 변경 후 도착한 과거 리플레이 응답은 모달을 다시 열지 않는다.
- 일반 성공 700ms, 이정표/T1 성공 1100ms 강조를 제공한다. T1은 `MASTER · T1 COMPLETE`로 구분하며 모션 줄임 설정을 준수한다. 서버 결과 확인 최소 대기 300ms 계약은 유지한다.

## 실행 결과

Chromium 1440×900 및 390×844 CSS viewport, reduced motion 켜짐. 열 검사 그룹 PASS, 브라우저 오류 0. 모바일 너비 초과 없음.

1. 현재 팩의 다음 티어 합법 후보와 능력 미리보기.
2. 슬롯 필터·지갑 갱신 간 입력 노드 보존·빈 슬롯 유지.
3. 종료 자동 선택 결과 표시.
4. 초기화 결과 확인 후 퀴즈 이동.
5. 초기화 결과 확인 후 기존 보관 잠금 공 선택·출전.
6. 최근 경기의 원래 공 인스턴스로 재도전.
7. 새 경기 배정 후 늦은 리플레이 응답 무시.
8. 무효 경기의 사유와 승자 없음 표시.
9. T1 MASTER 강조 및 reduced motion.
10. HTML 이벤트 속성이 포함된 두 학생 이름을 합쳐도 교사 경기 선택기에 텍스트로만 표시.
