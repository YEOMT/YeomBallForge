# Yeom Ball Forge

퀴즈 정답으로 강화권을 모으고 **20티어에서 1티어로 공을 성장시키는** 학생 참여형 자동 전투 게임입니다. 교사 1명과 학생 최대 30명이 브라우저로 참가합니다.

- [공개 게임](https://yeomt.github.io/YeomBallForge/)
- [배포 및 실시간 서버 연결](docs/deployment.md)
- [강화 경제와 정확한 확률 계산](docs/economy.md)

공개 정적 사이트에는 **샘플 퀴즈 → 강화·볼 선택 → CPU 토너먼트/30인 럼블**을 완주하는 연습 모드와 모든 볼을 비교하는 실험실이 있습니다. 여러 기기의 실제 교실 참여에는 Node.js WebSocket 서버 연결이 필요합니다. 서버가 미설정된 공개 빌드는 해당 상태를 표시하며 연습을 실제 교실 경기로 표시하지 않습니다.

## 교실에서 실행

Node.js 22.12 이상과 npm이 있는 교사 PC에서 실행합니다. 검증 환경은 Node.js 24입니다.

```sh
git clone --branch main https://github.com/YEOMT/YeomBallForge.git
cd YeomBallForge
npm ci --ignore-scripts
npm start
```

1. 교사는 `http://localhost:3000/`에서 **새 방 만들기**를 누릅니다. 로컬 개발 기본 비밀번호는 `forge`입니다. 수업용 비밀번호는 `.env.example`을 `.env`로 복사하고 `TEACHER_PASSWORD`에 지정합니다.
2. 기본 20문항을 쓰거나 UTF-8 TXT 문제은행을 올립니다. 한 줄은 `문제|정답|오답1|오답2|오답3`입니다. [5문항 예시](public/sample-quiz.txt)를 사용하면 문항 수를 5로 설정합니다.
3. 모드·문항 수·시간을 정한 뒤 QR 또는 주소와 6자리 코드를 공유합니다. 로컬 수업은 학생 기기에서 접근할 수 있는 교사 PC의 LAN 주소가 필요합니다.
4. 학생이 모이면 퀴즈를 시작합니다. 교사는 일시정지·재개, 다음 단계 진행, 토너먼트 중계 경기 선택을 할 수 있습니다.
5. 새 판에서는 문제은행과 참가자를 유지하고 재화·빌드·전투 상태를 초기화합니다. 진행 중 새 참가자는 다음 판을 기다립니다.

방과 재접속 토큰은 서버 메모리에 보관합니다. 같은 탭을 새로고침하면 역할을 복원하고, 같은 토큰으로 다시 연결하면 최신 연결이 역할을 이어받습니다. 서버 재시작 시 진행 중인 방은 만료됩니다. 방 수명은 12시간, 모든 연결이 끊겼을 때의 만료 시간은 15분입니다.

## 강화와 볼 선택

기본 설정은 퀴즈 20문항·120초, 강화 120초입니다. 최초 답만 채점하고 **기본 10장 + 정답당 2장**을 한 번 지급합니다. 강화 시도는 1장, 강화 유지권은 2장입니다.

| 목표 티어 | T19~T11 | T10 | T9 | T8 | T7 | T6 | T5 | T4 | T3 | T2 | T1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 성공률 | 100% | 85% | 80% | 70% | 60% | 50% | 40% | 30% | 22% | 15% | 10% |

- **T20**에서 기본 볼로 시작합니다. **T18부터** 승급할 때마다 해당 티어의 최소 두 종류 중 하나를 선택해야 다음 강화를 할 수 있습니다.
- **T10에서** 화염·물결·번개·대지·자연·검술·공간·소환 중 한 경로를 선택합니다. 이후 승급에는 해당 경로 2종과 공용 6종이 등장합니다. 공용 볼을 골라도 성장 경로는 유지합니다.
- T9 이상에서 실패하면 한 티어 하락합니다. 한 번 도달한 T10 아래로는 떨어지지 않습니다. 강등 시 그 티어에서 선택했던 공으로 돌아가며 상위 티어의 능력치는 가져오지 않습니다.
- 유지권은 적용을 켠 상태에서 실제 하락을 막을 때만 소모합니다. 성공이나 T10 하한에서의 실패로는 소모하지 않습니다.
- T10 최초 도달 시 딱 한 번 1% 확률로 히든 제안을 받습니다. 수락하면 일반 능력을 히든 능력으로 교체하고 이후 티어에서도 해당 히든 계열을 선택할 수 있습니다.
- 출전은 **현재 공**으로 확정합니다. 최고 도달 기록은 별도로 표시합니다. 시간이 끝나면 남은 경로·볼 선택을 유효한 기본값으로 확정합니다.

콘텐츠는 **26개 전투 유형, 26개 원본 초상화, 268개 티어별 형태**로 구성합니다. 같은 전투 유형의 상위 티어는 능력치와 형태를 발전시킵니다. 268개를 모두 서로 다른 공격 알고리즘으로 세지 않습니다.

검격·회전 삼도·잔상 돌진·연장 주먹·예고 광선·빙결 감속·포털 이동·사역마·사슬 끌기·박자 음파·탄 흡수 반격·피격 분노 등은 실제 전투 판정에 적용합니다. 각 볼의 발동 조건·약점·능력치는 도감과 선택 카드에서 비교할 수 있습니다.

화염 → 자연 → 대지 → 번개 → 물결 → 화염의 순환 상성을 사용합니다. 유리한 속성 피해는 1.20배, 불리하면 0.85배입니다. 검술·공간·소환과 공용 볼은 개별 정의의 속성 또는 무속성을 사용합니다.

## 경기와 관전

| 방식 | 호스트 화면 | 학생 화면 |
|---|---|---|
| 토너먼트 | 동시에 진행되는 최대 4경기 중 선택한 1경기를 중계 | 자신의 경기가 진행 중이면 그 경기를 우선 관전. 대기·탈락 시 다른 경기 관전 |
| 30인 럼블 | 흰 전장에서 전체 자동 전투를 중계 | 전장 캔버스 없이 자기 공·HP·생존 여부·최종 등수·처치자 표시 |
| 토너먼트 + 럼블 | 토너먼트 후 모든 공을 초기화해 럼블 진행 | 각 단계에 맞는 관전 규칙 적용 |

일반 토너먼트는 45초, 결승은 60초입니다. 판정은 남은 HP 비율·유효 피해 비율·시드 추첨을 사용합니다. 럼블은 45초부터 전장 축소, 90초부터 압박, 최대 120초이며 동시에 탈락하면 공동 순위입니다. 흰 배경·진한 외곽선·HP 현재/최대·피해 숫자로 전투 정보를 표시합니다.

서버는 60Hz 고정 틱으로 판정하고 호스트와 토너먼트 학생에게 약 12.5Hz 관전 프레임을 전송합니다. 럼블 학생에게는 약 1초마다 개인 요약만 보냅니다. 전장 좌표·투사체·다른 학생의 개인 프레임은 보내지 않습니다. 브라우저 렌더링과 효과 설정은 전투 결과를 바꾸지 않습니다.
