# YeomBallForge v2.1

퀴즈를 풀어 공을 T20 → T1로 키우고, 준비된 학생끼리 자동 전투하는 교실 게임입니다. 교사 1명과 학생 최대 30명이 참여합니다. 이 브랜치는 v2.1 구현이며 공개 서비스의 배포 완료를 뜻하지 않습니다.

## 실행

Node.js 22.12 이상이 필요합니다. 검증 환경은 Node.js 24입니다.

```sh
npm ci --ignore-scripts
npm start
```

`http://localhost:3000/`에서 방을 만듭니다. 로컬 개발 비밀번호는 `forge`이며, 수업용 비밀번호는 `.env.example`을 참고해 비공개 `.env`의 `TEACHER_PASSWORD`에 설정합니다. UTF-8 문제은행은 한 줄에 `문제|정답|오답1|오답2|오답3` 형식입니다. [예시](public/sample-quiz.txt)를 사용할 수 있습니다.

학생에게는 교사 PC의 접근 가능한 LAN 주소 또는 실제 HTTPS/WSS 서버 주소가 필요합니다. GitHub Pages만으로는 여러 기기의 실시간 방을 운영하지 않습니다. 서버 미설정 상태에서도 [오프라인 CPU 연습](docs/v2.1-practice.md)은 가능합니다. 연습에는 실제 학생 Elo와 보상이 없습니다.

## 랭킹 도전

기본 15분, 교사 설정 5~30분입니다. 학생은 퀴즈·강화·보관·경기를 자유롭게 오갑니다. 정답마다 강화권 2장을 즉시 받고, 기본 10장은 학생당 한 번만 받습니다. 같은 문항의 보상 재출제에는 90초와 서로 다른 다른 문항 `min(4, 은행 크기−1)`개 조건이 모두 필요합니다.

독립된 공 3개가 강화권·유지권 지갑을 공유합니다. 빈 슬롯에는 무료 T20 공을 만들 수 있습니다. 보관 잠금은 출전을 허용하고 변경을 막습니다. 대기열·경기에 확정된 공은 수정할 수 없으며 다른 슬롯과 퀴즈는 계속 사용할 수 있습니다.

준비된 학생끼리 최대 15경기를 동시에 진행합니다. Elo는 시작 1000, K=32이며 완료된 정식 학생 경기만 반영합니다. 경기당 최대 40초, 30초부터 교착 해소 압박을 적용합니다. 학생은 자신의 경기를 보고, 교사는 선택한 경기 하나를 송출합니다. 송출 대상은 교사가 변경할 때까지 유지됩니다.

최근 3경기의 실제 기록을 재생하거나 마지막 상대의 고정 빌드를 상대로 보유 공·특성을 비교할 수 있습니다. 비교 연습은 복사본에서 실행하며 인벤토리와 원본 경기 결과를 바꾸지 않습니다. 재생·연습·시연에는 강화권과 Elo를 지급하지 않습니다.

일시정지는 논리시간을 멈춥니다. 수업 종료는 신규 보상·강화·매칭을 막고 진행 경기와 승인된 선택을 최대 45초 동안 정리합니다. 새 판은 전투력·지갑·레이팅을 초기화합니다. 방과 복구 토큰은 서버 메모리에 있으며 서버 재시작을 넘는 영구 복구는 지원하지 않습니다.

## 강화와 선택

모든 강화는 1장을 소비합니다. 목표 T19부터 T1까지 성공률은 순서대로 **95, 92, 90, 88, 85, 82, 80, 78, 75, 72, 68, 60, 52, 44, 35, 26, 18, 10, 3%**입니다. 기준은 공통 경제 설정 한 곳이며 최종 단일 시도 3%와 한 수업의 T1 도달률은 다릅니다.

- 현재 T20 실패: 유지. 현재 T19~T11 실패: 한 단계 하락. 현재 T10~T2 무보호 실패: 해당 공 T20 초기화.
- 유지권 가격은 1개당 강화권 2장. 목표 T18~T5 보호는 1개, T4~T2는 2개, T1은 3개 필요합니다. 실제 하락·초기화를 막은 실패에서만 소비합니다.
- 보호 구매와 시도는 원자적으로 처리합니다. 부족한 보호를 자동 무보호로 바꾸지 않습니다.
- 결과 문구 → 확인 → 필요한 경로·공·히든·특성 선택 순서입니다. 재접속해도 승인된 결과와 후보를 유지합니다.
- T18부터 폼을 선택하고 T10부터 8개 성장 방향과 공당 전술 특성 1개를 선택합니다. 각 고급 티어는 경로 전용 5개와 공용 6개를 제공합니다. 공용 선택도 성장 방향을 보존합니다.
- 히든은 슬롯별 세션 최초 T10에서 1%로 한 번만 판정합니다. 초기화·삭제·재생성으로 재추첨하지 않습니다.

콘텐츠는 **50개 실제 전투 프로필, 508개 티어별 폼, 기존 26개 원본 초상화**입니다. 폼 개수를 서로 다른 기믹 개수로 세지 않습니다. 10개 특성은 프로필마다 호환 후보 3개만 제공합니다. 수업 팩은 방 전체에 동일하게 적용합니다. 공개 원형의 이미지·음원·소스를 추가 복사하지 않았습니다.

기본 HP는 `200+6×level`, 기본 공격 계수는 `10+0.5×level`입니다. 유리 속성 ×1.20, 불리 속성 ×0.85이며 실제 출전 속성을 표시합니다. 공통 시뮬레이터는 외형(구체/초상화/혼합), 효과량, 모션 줄임, 음량과 독립적으로 판정합니다.

## 기존 모드

토너먼트·럼블·토너먼트 후 럼블은 한 차례 퀴즈 → 강화 → 한 공 출전 흐름을 유지합니다. 강화 규칙·특성·전투 HUD는 공유하고, 3슬롯·반복 퀴즈·Elo는 랭킹 모드에만 적용합니다. 럼블 학생에게는 자기 정보·생존/탈락·순위·처치자만 전송하고 전체 전장은 교사만 표시합니다.
